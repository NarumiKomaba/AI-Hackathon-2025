# Antigravity Technical Guide & Integration

Antigravityは、ハッカソンにおける開発効率を最大化するために設計された、高度なエージェント型AIアシスタントです。

## 1. 概要
Antigravityは、コンテキストを深く理解し、自律的にタスクを遂行する能力を備えています。単なるコード補完に留まらず、設計から実装、検証までを一貫してサポートします。

## 2. コア機能

### 2.1 高度なコード生成とリファクタリング
- **コンテキスト理解**: プロジェクト全体の構造、型定義、デザインシステムを考慮したコードを生成します。
- **リファクタリング**: 既存コードの負債を特定し、公式ドキュメントやベストプラクティスに基づいた最適化を提案・実施します。

### 2.2 ドキュメント駆動開発の支援
- **詳細設計書の自動生成**: 要件から詳細設計ドキュメントを構成し、ディレクトリ構造やAPI仕様を定義します。
- **仕様の整合性維持**: 実装とドキュメントの乖離を最小限に抑えるため、変更に応じた追従更新をサポートします。

### 2.3 自律的な検証
- **環境構築とテスト**: 必要に応じて環境変数の設定や、テストスクリプトの作成・実行を代行します。
- **デバッグ**: ログやエラースタックを解析し、根本原因の特定と修正案の適用を行います。

## 3. 活用シナリオ

| フェーズ | 具体的な活用方法 | 期待される効果 |
| :--- | :--- | :--- |
| **企画・設計** | `detailed_design.md` の作成、APIエンドポイントの定義 | 開発の共通認識を早期に確立 |
| **実装** | コンポーネント作成、ビジネスロジックの実装 | コーディング時間の50%以上削減 |
| **検証** | Playwright等によるE2Eテスト、バグ修正 | 品質向上と手戻りの最小化 |

## 4. 開発チームへのメッセージ
Antigravityは、皆様の創造性を物理的な実装の制約から解放することを目指しています。技術的な懸念点や実装の詳細はAntigravityに任せ、より本質的な「価値提供」に集中してください。
